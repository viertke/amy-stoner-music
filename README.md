## Workflow

### Making Updates to Live Squarespace Page
1. Edit files in your local `pages/` folder
2. Copy the updated code
3. Paste into Squarespace code blocks
4. Preview and publish on Squarespace
5. Commit changes to GitHub:
   - Open GitHub Desktop
   - Review changes
   - Write commit message
   - Click "Commit to main"
   - Click "Push origin"

### Working with Claude
1. Drag files from your local folder into Claude chat
2. Claude reads and creates updated versions
3. Download updated files
4. Save to your local folder (replacing old versions)
5. Commit and push via GitHub Desktop
